# مشروع تطبيق ملاحة للعراق

وثيقة تمهيدية لتجميع الرؤية الفنية والمنتج لتطبيق ملاحة مخصص للعراق، مع روابط لملفات التصميم التفصيلية والخطط التنفيذية.

## لمحة سريعة
- **المنصة المستهدفة:** iOS وAndroid (Kotlin Multiplatform أو Flutter كخيار بديل).
- **الجمهور:** سائقي الأجرة والتوصيل، مستخدمون يوميون، شاحنات.
- **الأولويات:** دقة المسار، دعم اللغتين العربية/الكردية، العمل دون اتصال، وتنبيهات مجتمعية موثوقة.

## الملفات المهمة
- `docs/iraq_navigation_app_design.md`: تصور تجربة المستخدم والميزات الأساسية باللهجة المحلية.
- `docs/project_plan.md`: خطة التنفيذ التقنية والمنتج (MVP، البنية، البيانات، خارطة الطريق).
- `docs/backend_api.md`: تصور أوّلي لواجهات البرمجة المطلوبة لخدمة التطبيق.

## لمحة عن خارطة الطريق
1. **MVP (8–10 أسابيع):** خرائط أساس، بحث، ملاحة خطوة بخطوة، تنبيهات مجتمع أساسية، وضع ليلي، لغات عربية/كردية.
2. **تحسينات (10–14 أسبوعاً):** مسارات بديلة ذكية، خرائط دون اتصال، نظام سمعة للتنبيهات، مشاركة الرحلة الحية.
3. **إطلاق موسّع:** دعم الشاحنات/الدراجات، طبقة حوادث طقس، تحسينات ML للتعرف على السرعة.

## كيفية المساهمة
1. مراجعة ملفات `docs/` لفهم المتطلبات والقيود.
2. اقتراح تعديلات عبر فروع منفصلة مع وصف واضح للتغيير.
3. الالتزام باتفاقية الرسائل الواضحة واللغات المزدوجة عند إضافة واجهات أو نصوص للمستخدم.
